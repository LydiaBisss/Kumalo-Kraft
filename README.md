# KumaloKraft

KumaloKraft is a responsive e-commerce-style website built with ASP.NET Core MVC. The website showcases handcrafted products through a clean and visually focused interface.

## Live Deployment

The application was deployed to **Microsoft Azure** to make the website accessible online.

Deployment demonstrates experience with:

* ASP.NET Core application deployment
* Microsoft Azure
* Cloud hosting
* Web application configuration
* Publishing an ASP.NET Core MVC application

## Features

* Responsive homepage
* Hero section
* Product showcase
* Product images and descriptions
* Navigation between website pages
* Responsive design
* Hover effects and visual interactions

* Shop-focused user interface

## Deployment

The application was published to Microsoft Azure as an ASP.NET Core web application.

```text
User
  ↓
Web Browser
  ↓
Microsoft Azure
  ↓
ASP.NET Core MVC Application
  ↓
Razor Views
  ↓
KumaloKraft Website
```

Deploying the project to Azure provided experience with taking an application from local development to a cloud-hosted environment.
